# 系统面板 · SillyTavern 扩展

给角色卡加一个「异界超维系统」：任务、积分、商城、抽奖、背包，外加一个能直接使唤系统的对话框。
系统是独立人格（傲娇损友 + 奸商），能自己派活、推销、吐槽，正文里的它和面板上的它共用一本账。

## 安装

在酒馆里打开「扩展」面板，找到「安装扩展」的输入框，填本仓库地址：

```
https://github.com/yka9933-max/moyu-system-panel
```

装完刷新页面，在扩展列表里确认「系统面板」是启用状态。酒馆的魔杖菜单里会多一个「系统面板」入口。

## 配套世界书（建议一起装）

`worldbook/异界超维系统.世界书.json` 是给正文模型看的规矩：系统是什么、怎么开口、任务怎么派、积分和商城怎么算价。
插件不依赖它——不挂也能跑，插件会自己把整套设定一起发给正文，只是每轮多花一些字；挂了就只发当前状态，不重复。

装法：酒馆「世界书」面板 → 导入 → 选这个文件 → 导入后勾成「全局世界书」。

## 第一次打开要做的

面板需要接一个 OpenAI 兼容接口（地址 / 密钥 / 模型），用来生成任务、商品和系统台词。
这个配置存在浏览器本地，不跟着账号走，换设备要重填一次。

## 说明

- 存档按聊天分开，存在酒馆的聊天元数据里，导出聊天会跟着走。
- 不依赖酒馆助手，全部走酒馆官方接口。
- 系统规则与商品价格写死在代码里，模型只能填名称和作用，不能自己定价。
